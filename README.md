## Amazon Sales Dashboard | Power BI

## Project Overview

The **Amazon Sales Dashboard** is an interactive Business Intelligence project developed using **Microsoft Power BI** to analyze e-commerce sales performance. The dashboard provides a comprehensive view of **sales, revenue, orders, products, customers, payment methods, discounts, taxes, and shipping costs**. Using Power Query and DAX, raw sales data is transformed into meaningful KPIs and interactive visualizations to identify sales trends, product performance, customer behavior, and key business insights.

## Business Objective

The main objective of this project is to transform raw Amazon sales data into an interactive analytical dashboard that helps users:

* Monitor overall sales and revenue performance
* Track order volume and order status
* Identify top-performing products, brands, and categories
* Analyze customer purchasing behavior
* Understand payment method performance
* Analyze monthly sales and revenue trends
* Monitor discounts, taxes, and shipping costs
* Generate actionable business insights for data-driven decision-making

 ## Dashboard Features
